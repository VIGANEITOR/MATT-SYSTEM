# Borradores de trabajo

Capítulos en iteración antes de incorporarse a una versión nueva de un brief. Cada revisión de trabajo se guarda como
archivo nuevo (`_r1`, `_r2`, …) y no se sobrescribe. Un borrador **no rige** hasta integrarse en una versión aprobada.

| Borrador | Destino | Revisión vigente |
|---|---|---|
| [Capítulo 3: Alcance, releases y áreas complementarias](Maestro_v1.4_Cap3_Releases_r1.md) · [versión Word para responder](Maestro_v1.4_Cap3_Releases_r1.docx) | Brief Maestro v1.4 | r1 (superada) |
| [Capítulo 3, revisión r2](Maestro_v1.4_Cap3_Releases_r2.md) · [Word](Maestro_v1.4_Cap3_Releases_r2.docx) | **Integrado** en Brief Maestro v1.4 | r2 |

Las respuestas del autor en Word se guardan como `<nombre>_r1_respuestas.docx` junto al borrador; la revisión siguiente (r2) se redacta a partir de ellas.
