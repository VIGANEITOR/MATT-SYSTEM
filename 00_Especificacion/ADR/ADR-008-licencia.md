# ADR-008 — Propiedad intelectual y licencia del código

- **Estado**: Propuesto
- **Responsable**: Producto + legal
- **Fecha límite**: Antes de R1

## Contexto
Brief Maestro v1.1, §15.2. El repositorio público se inicializó con licencia MIT (archivo `LICENSE`), que rige de forma
provisional. Este ADR debe confirmarla o reemplazarla; una opción frecuente es MIT o Apache-2.0 para el código y
CC BY 4.0 para documentación y datos.
