# Política de seguridad

MATTX aún no tiene código liberado (estado: especificación objetivo).

## Reportar una vulnerabilidad

No abras un issue público. Usa el reporte privado de GitHub: pestaña **Security → Report a vulnerability** de este
repositorio (Constitución, Art. 40). Incluye la descripción, los pasos para reproducirla y el impacto esperado.

## Lo que nunca debe subirse

Secretos, credenciales, datos personales ni documentos de perfil sensible (contratos, planos reservados, estudios
confidenciales), conforme al Artículo 39 de la Constitución. Si encuentras uno en el repositorio, repórtalo por el
canal privado.
